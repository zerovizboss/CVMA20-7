## 🔐 **ACCESSING YOUR REPORTS**

### **Step 1: Login to Salesforce**
1. Navigate to your CVMA Salesforce org
2. Use your Treasurer or Officer credentials
3. Ensure you have proper financial reporting permissions

### **Step 2: Navigate to Reports**
1. Click the **App Launcher** (9 dots icon) in the top left
2. Search for "Reports" and select the Reports app
3. Look for the "**CVMA Financial Reports**" folder

### **Step 3: Run Financial Reports**
1. Select your desired report from the CVMA Financial Reports folder
2. Click "**Run Report**" to generate with current data
3. Use filters to customize date ranges and criteria
4. Click "**Save**" to preserve customized reports

### **Step 4: Schedule Automated Reports**
1. Open any report you want automated
2. Click "**Subscribe**" in the top right
3. Choose frequency: Daily, Weekly, Monthly, or Quarterly
4. Add email recipients (treasurer, officers, etc.)
5. Set report delivery schedule

## 🔧 **TROUBLESHOOTING GUIDE**

### **Common Issues & Solutions**

#### **Issue: "Report not found" Error**
- **Solution**: Check your user permissions with system administrator
- **Cause**: User profile may not have financial reporting access

#### **Issue: "No data displayed" in Reports**
- **Solution**: Verify date range filters and opportunity stage criteria
- **Cause**: Report filters may be too restrictive

#### **Issue: Dashboard not refreshing**
- **Solution**: Dashboards refresh daily - check "Last Updated" timestamp
- **Cause**: Dashboard scheduled refresh may be pending

#### **Issue: Can't schedule automated reports**
- **Solution**: Verify you have "Subscribe to Reports" permission
- **Cause**: User profile permissions may need update

### **Getting Help**
1. **System Administrator**: Contact for permission or configuration issues
2. **User Manual**: Reference this guide for standard operating procedures
3. **Salesforce Help**: Use in-app help for platform-specific questions
4. **Chapter Leadership**: Escalate financial questions to appropriate officers

## 🚀 **ADVANCED FEATURES**

### **Custom Report Building**
Create specialized reports for unique chapter needs:
1. Click "**New Report**" in Reports app
2. Select "**Opportunities**", "**Campaigns**", or "**NPSP objects**"
3. Add fields relevant to your analysis
4. Save to "**My Reports**" or "**CVMA Financial Reports**" folder

### **Report Sharing**
Share financial insights with chapter leadership:
1. Open any report and click "**Share**"
2. Add email addresses for officers and board members
3. Set access level (View only or Edit)
4. Include personal message explaining the analysis

### **Data Export**
Export financial data for external analysis:
1. Run desired report with appropriate filters
2. Click "**Export**" and choose format (Excel, CSV)
3. Use exported data for budgeting or external accounting
4. Maintain data security - encrypt sensitive files

### **Dashboard Customization**
Modify dashboards for your chapter's priorities:
1. Open dashboard and click "**Edit**"
2. Add/remove components based on reporting needs
3. Adjust chart types and date ranges
4. Save as new dashboard for custom analysis
