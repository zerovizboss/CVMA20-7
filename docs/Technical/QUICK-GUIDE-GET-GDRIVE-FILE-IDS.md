## 🚀 **Fastest Method: Google Drive Web Interface**

### **Step 1: Open Bylaws Folder**

Link: https://drive.google.com/drive/folders/1QMl79m0xhWK79X0Ojn8XmGkvseH57TnH?usp=sharing

### **Step 2: Get File IDs for Each File**

**For each file in the list below:**

1. **Right-click the file** → Select **"Get link"**
2. **Click "Copy link"** (link is now in clipboard)
3. **Paste the link** into notepad/text editor
4. **Extract the file ID** from the URL

**URL Format**:
```
https://drive.google.com/file/d/[FILE_ID_HERE]/view?usp=sharing
```

**Example**:
- URL: `https://drive.google.com/file/d/1ABC123xyz456DEF/view?usp=sharing`
- File ID: `1ABC123xyz456DEF`
