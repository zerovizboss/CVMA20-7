## 📝 **Naming Conventions**

### **File Naming Standards**

**Pattern**: `Type-Number-Description-Date.ext`

**Examples**:
```
✅ GOOD:
- Form-100-Membership-Application-01OCT25.pdf
- CVMA-National-Bylaws-Revision-V-Signed.pdf
- 2025-01-Treasurer-Report.pdf

❌ AVOID:
- form 100.pdf (no structure, spaces)
- membership app.pdf (unclear type)
- document1.pdf (no description)
```

### **Folder Naming Standards**

**Pattern**: `##-Category-Name/`

**Rationale**:
- Numbers (01, 02, etc.) = Force sort order
- Hyphens = Better URL compatibility than spaces
- Title Case = Professional appearance

**For EACH file uploaded**:

1. Right-click the file → **Share**
2. Click **Change** next to "Restricted"

4. Ensure role is set to **Viewer** (not Editor!)
5. Click **Copy link**

## 🚨 **Important Notes**

### **Backup Strategy**

**Google Drive is NOT the source of truth!**

- **Source of Truth**: `C:\Users\zerov\OneDrive\Documents\CVMA\`
- **Google Drive**: Distribution copy for Salesforce integration
- **Always maintain** OneDrive originals
- **If Drive file is deleted**: Re-upload from OneDrive

### **Permission Management**

**Two Permission Levels**:

1. **Public Documents** (Most files)
   - Sharing: "Anyone with link can view"
   - Access: All CVMA members via Salesforce

2. **CEB-Only Documents** (Folder: 11-CEB-Only)
   - Sharing: Specific CEB officer emails only
   - Access: CEB officers via Salesforce

### **Storage Considerations**

**Google Drive Free Tier**: 15GB
**CVMA Documents Estimate**: ~500MB-1GB total

**If you exceed 15GB**:
- Consider Google Workspace upgrade ($6/user/month for 30GB)
- OR use chapter's existing Google Workspace if available
- OR selective upload strategy (priority docs only)
