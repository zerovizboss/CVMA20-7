## 📅 **Report Subscription Configuration**

### **Monthly Report Subscriptions**
Navigate: **Reports → CVMA Financial Compliance → Monthly Budget Performance → Subscribe**

#### **Subscription 1: Monthly Budget Performance**
```
Subscription Details:
├── Report: Monthly Budget Performance
├── Frequency: Monthly
├── Run Date: 5th of each month
├── Time: 8:00 AM (Chapter timezone)
├── Format: Excel + PDF attachments
├── Running User: Treasurer (ensures permissions)
└── Email Template: Monthly Budget Performance Template
```

**Recipient Configuration:**
```
PRIMARY RECIPIENTS (Required):
├── Treasurer (primary financial officer)
├── Chapter President (executive oversight)
└── Vice President (backup authority)

SECONDARY RECIPIENTS (CC):
├── Secretary (record keeping)
├── Road Captain (event liaison)
└── Designated Financial Advisor (if applicable)

NOTIFICATION SETTINGS:
├── Delivery Confirmation: Yes
├── Failure Notification: Treasurer + President
└── Retry Logic: 3 attempts over 24 hours
```

#### **Subscription 2: Monthly Transaction Detail**
```
Subscription Details:
├── Report: Monthly Transaction Detail
├── Frequency: Monthly
├── Run Date: 3rd of each month (before budget performance)
├── Time: 7:00 AM
├── Format: Excel (detailed analysis)
├── Recipients: Treasurer + Secretary
└── Purpose: Detailed reconciliation support
```
